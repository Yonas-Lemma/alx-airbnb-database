# Database Seed Data for Airbnb Database

This repository contains SQL scripts to populate the Airbnb-like application database with sample data.

## Purpose

The `seed.sql` file includes sample data for the following tables:
- User
- Property
- Booking
- Payment
- Review
- Message

## Usage

To populate the database with sample data, execute the `seed.sql` file in your SQL database management system (e.g., PostgreSQL, MySQL).

```sql
-- Example command to run the seed script
\i path/to/seed.sql
